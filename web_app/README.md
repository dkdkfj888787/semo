# موقع ويب تطبيق Index

هذا هو موقع الويب الرسمي لتطبيق Index، وهو تطبيق مشاهدة أفلام ومسلسلات متطور.

## محتويات الموقع

- الصفحة الرئيسية مع فيديو خلفية
- قسم المميزات
- قسم لقطات الشاشة
- قسم التحميل
- قسم عن التطبيق
- تذييل الصفحة مع معلومات الاتصال
- دعم اللغتين العربية والإنجليزية

## كيفية تشغيل الموقع

1. تأكد من تثبيت Python 3 على جهازك
2. انتقل إلى مجلد `web_app`
3. قم بتشغيل الأمر التالي:

```bash
python3 server.py
```

4. افتح المتصفح وانتقل إلى `http://localhost:12000`

## هيكل الملفات

- `index.html` - الصفحة الرئيسية باللغة العربية
- `en.html` - الصفحة الرئيسية باللغة الإنجليزية
- `css/style.css` - ملف CSS الرئيسي
- `js/main.js` - ملف JavaScript الرئيسي
- `images/` - مجلد الصور والفيديوهات
- `server.py` - خادم ويب بسيط
